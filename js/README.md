# Clínica NutriVida

Proyecto frontend académico para DSY1104.

## Tecnologías
HTML5 semántico, CSS externo/responsive, JavaScript, LocalStorage y Git/GitHub.

## Funcionalidades
Página principal, Nosotros, Blog (2 publicaciones + detalle), Contacto, Registro, Login con roles, catálogo dinámico, detalle con LocalStorage, lista de selección con LocalStorage, área administrativa, mantenedor de servicios, mantenedor de usuarios, responsive, video y mapa.

## Nota
La autenticación con LocalStorage es solo una simulación para un prototipo frontend académico. No debe usarse como seguridad real en producción.

## Ejecutar
Abrir index.html o usar VS Code + Live Server.

Crear repositorio público, copiar el proyecto, hacer commits descriptivos y usar `git push`.
